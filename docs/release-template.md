## 新しいバージョンへの更新

**すでに使っている場合**

1. 下の **Assets** から `pixel-walker-<バージョン>.zip` をダウンロードし、展開する
2. 展開してできた `pixel-walker` フォルダの**中身**を、今使っているフォルダ（最初に読み込んだフォルダ）に**上書きでコピー**する
3. Chrome で `chrome://extensions` を開き、Pixel Walker の「再読み込み」ボタン（丸い矢印）を押す

同じフォルダに上書きすれば、設定（選んだキャラクターなど）はそのまま引き継がれます。

**初めて入れる場合**

1. 下の **Assets** から `pixel-walker-<バージョン>.zip` をダウンロードし、展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開してできた `pixel-walker` フォルダを選ぶ

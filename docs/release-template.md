## 更新のしかた

1. 下の **Assets** から `pixel-walker-<バージョン>.zip` をダウンロードし、展開する
2. 展開してできた `pixel-walker` フォルダの**中身**を、今使っているフォルダに**上書きでコピー**する
3. `chrome://extensions` で Pixel Walker の「再読み込み」ボタンを押す（設定はそのまま引き継がれます）

初めて入れる方は [README のインストール](https://github.com/ItsukiYokoyama/pixel-walker#インストール) をご覧ください。
